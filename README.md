🏎️ F1 Dashboard v1.0.0 — The Ultimate Fan Experience

Welcome to the initial release of the F1 Dashboard! This is an unofficial, feature-rich fan dashboard built to bring the excitement of Formula 1 to your screen with real-time data, deep analytics, and a stunning, responsive UI.

🌐 Live Demo: https://f1dash-lime.vercel.app/

📊 Live & Real-Time Data
- Live Timing: Real-time race tracking and session updates.
- Telemetry: Deep dive into car telemetry and session data.
- Points Progression: Interactive scroll-graphs visualizing the championship leadership battle throughout the season.

🏆 Championships & Standings
- Driver & Team Standings: Up-to-date Driver and Constructor championships.
- Champions History: Explore the legacy of F1 with a comprehensive list of World Champions by year.

🏎️ Drivers & Circuits
- Driver Profiles: Detailed career stats and information for every driver.
- Head-to-Head Comparison: A dedicated tool to compare drivers side-by-side.
- Season Calendar: Full season schedules with dedicated pages for each Grand Prix.
- Circuit Maps: Beautiful SVG track maps featuring a curated collection of 25+ tracks with a smart fallback to Wikimedia Commons.

🛠️ Tech Stack & Architecture
- Built with modern, high-performance web technologies:
- Framework: Next.js 15 (App Router) with React 19 & TypeScript (Strict Mode).
- Styling: Tailwind CSS 4 with custom Light/Dark theme tokens and premium typography (Tektur, Manrope, Orbitron, JetBrains Mono).
- Data Sources: Jolpica (Ergast), OpenF1, API-SPORTS, and Wikimedia Commons.
- Performance: Smart caching strategies using ISR (Incremental Static Regeneration) and force-dynamic routing only where necessary (Live & Compare pages).
- PWA: Fully installable Progressive Web App with a service worker for an app-like mobile experience.
- Mobile Optimized: Wide charts and graphs feature horizontal scrolling with elegant fade gradients for a seamless mobile UX.
